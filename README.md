# tree-node-times — Cálculo de Tempos em Árvore de Nós (CodeSandbox)

Projeto educacional minimalista para cálculo de tempos de processamento em estruturas de árvore. Implementação básica em TypeScript/JavaScript.

## 📚 Sobre
Projeto simples (criado no CodeSandbox) demonstrando:
- Estrutura de dados de árvore com nós
- Cálculo de tempos de execução por nó
- Propagação de tempos pai → filhos

## 🛠 Tech Stack
- **Language**: TypeScript / JavaScript
- **Environment**: CodeSandbox / Node.js

## 🚀 Como rodar
```bash
# No CodeSandbox: abra o link do demo
# Local:
npm install
npm start
```
